# SQL Data Warehouse Project

## Introduction

This project demonstrates the design and implementation of a **SQL-based Data Warehouse** using data extracted from **CRM (Customer Relationship Management)** and **ERP (Enterprise Resource Planning)** systems.

The source data is provided as **CSV files**, representing different business processes and entities such as customers, products, sales, and other operational data. The project follows a complete **ETL (Extract, Transform, Load)** process to convert raw source data into a structured and analytics-ready data warehouse.

The main objective of this project is to build a centralized data platform that integrates data from multiple source systems, applies data cleansing and transformation, and organizes the data into a suitable warehouse model for **reporting, analysis, and business intelligence**.

### Project Workflow

**CRM & ERP CSV Files → Extraction → Data Cleaning & Transformation → Data Warehouse → Analytical Queries & Reporting**

The project covers key data warehousing concepts, including:

* Data extraction from CRM and ERP source systems
* Data cleaning and validation
* Data transformation and integration
* Designing a **Star Schema**
* Creating **Fact and Dimension tables**
* Defining relationships between warehouse tables
* Handling business keys and surrogate keys
* Loading transformed data into SQL Server
* Writing SQL queries for data analysis and validation

This project is intended to demonstrate practical knowledge of **SQL, ETL, data modeling, and Data Warehouse development** in a real-world business scenario.
